# BARSA SHOPI v6.5 — Native Tile Pipeline

## Implemented
- Android ONNX Runtime tile inference path for AI Upscale.
- Binary localhost API (`/native-ai/register`, `/native-ai/infer`) — no Base64 for AI tensors.
- Model registration is persistent in Android cache and fingerprinted by SHA-256 + byte size.
- Verified models are only copied to the native cache when missing or changed.
- UpscaleEngine prefers Android native inference when available, then automatically falls back to WebGPU/WASM on any native error.
- Fixed-shape ONNX models are padded/cropped natively to the requested tile geometry.
- Native ORT sessions are cached per model and closed with the Android activity.
- NNAPI is requested first on Android 10+; CPU remains the ONNX Runtime fallback.
- Result metadata records the actual AI upscale provider used.
- Device diagnostics show when Native ONNX Tiles are available.
- Android version bumped to 6.5.0 / versionCode 65.
- GitHub APK artifact renamed to BARSA-SHOPI-v6.5-debug.

## Important boundary
The Java/Android source is wired for ONNX Runtime Android and the GitHub workflow will compile it with JDK 17 + Android tooling. This session does not contain a real Android/POCO F6 runtime, so native NNAPI throughput and real device inference must be validated by the APK build on the phone. WebGPU/WASM fallback remains active if the native path is unavailable.
