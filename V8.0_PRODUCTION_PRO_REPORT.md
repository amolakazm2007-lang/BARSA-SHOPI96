- Versioned automatic settings persistence with restore on launch.
- Manual Save Now and Reset controls.
- Saved model choices and processing/export preferences.
- User preferences are respected before applying the POCO F6 default profile.

## Device caveat
Real thermal behavior, Adreno WebGPU/NNAPI throughput and long 4K render stability still require the final v8 APK to be tested on the physical POCO F6. The source contains fallbacks intended to avoid hard render failure when a faster backend is unavailable.
