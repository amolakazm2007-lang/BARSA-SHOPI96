# BARSA SHOPI v6.4 Native Acceleration

## Added
- Android ONNX Runtime dependency (`onnxruntime-android:1.22.0`).
- `NativeAiRuntime.java` with a real ONNX session and inference self-test against the bundled SR model.
- Best-effort NNAPI enablement on Android 10+ with CPU fallback.
- JavaScript bridge methods for native AI capability and self-test results.
- Android version bumped to 6.4.0 / versionCode 64.
- Android runtime sync metadata bumped to 6.4.0.

## Important limitation
This stage verifies a real native ONNX runtime and inference path, but full per-frame video AI still uses the existing WebGPU/WASM processing pipeline. Moving full-frame/tile inference into native Android without expensive JS<->Java image serialization requires a dedicated native video/tensor pipeline; that is the next native phase.
