# BARSA SHOPI v8.6 — Native Face + Render Proof

## Scope
v8.6 moves face restoration closer to the Android native runtime and adds a user-exportable render proof report. The existing frame-perfect, blur-only, MP4 recovery, and manual model-selection behavior is preserved.

## Native Face AI
- GFPGAN / CodeFormer can use the localhost raw-binary Android ONNX Runtime path.
- Native model cache is checked before loading a 300+ MB face model into the WebView, avoiding unnecessary re-registration when the cached fingerprint matches.
- CodeFormer-style auxiliary float inputs are supported by the Android runtime through the fidelity value.
- Native output geometry is read from the ONNX tensor instead of being guessed from an upscale factor.
- If native face registration/inference fails, the model is disabled only for that native session and BARSA falls back to WebGPU/WASM without aborting the render.
- `faceProvider` is recorded in final render metadata.

## Render Proof
- Result screen now exposes `تقرير سلامة الرندر`.
- The JSON report includes frame-integrity diagnostics, MP4/track validation, A/V sync, AI providers, quality audit, render stability, output geometry/FPS and session metadata.
- Result summary shows Frame Perfect confirmation and native/web face provider when available.

## Android Native Runtime
- Native runtime capabilities now expose `nativeFaceApi`.
- `/native-ai/infer` accepts a bounded `fidelity` parameter.
- Runtime identifies the NCHW image input and creates bounded auxiliary tensors for compatible image-to-image models.
- Output tensor dimensions are validated before returning binary float data to the WebView.
