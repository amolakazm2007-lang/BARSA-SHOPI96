## Native RIFE
- تمت إضافة binary endpoint مستقل `/native-ai/rife` داخل Android localhost runtime.
- ينقل زوج Float32 CHW مباشرة بدون Base64.
- ONNX Runtime Android يحاول NNAPI ثم CPU fallback حسب دعم الجهاز.
- RIFEEngine يحاول Android Native أولاً حتى 1080p لكل inference.
- إذا فشل Native لأي موديل، يتم تعطيله لذلك الموديل في الجلسة والرجوع تلقائياً إلى WebGPU/WASM.
- 4K لا يُدفع قسراً عبر HTTP Native tensor path لأن زوج Float32 4K يستهلك ~190MB قبل activations؛ الثبات مقدم على ادعاء Native غير عملي.
- Frame Integrity Guard يبقى فعالاً؛ لا يوجد إسقاط فريمات مقصود في Governor.

## Denoise / Detail V3
### Chroma Denoise V3
- مرحلة مستقلة لإزالة ضوضاء اللون مع استرجاع luma الأصلي، لتقليل color speckles بدون صبغ texture البشرة/الشعر بمظهر بلاستيكي.
- موصولة إلى WebGPU وWebGL2 وCPU fallback.

### Multi-scale Detail Fusion V3
- يدمج micro detail مع structure detail عبر مقياسين مختلفين.
- منفصل عن Sharpen حتى لا يتحول إلى edge boost فقط.
- noise gate + limiter يقللان تضخيم grain والـ ringing.
- موصول إلى WebGPU/WebGL2/CPU fallback وإلى All Engine Boost.

## 4K Long Render Governor
تمت إضافة `RenderLoadGovernor` وهو لا يغير الدقة أو FPS المطلوبين. بدلاً من ذلك يقلل التوازي والطوابير:
- 4K / high FPS / AI-heavy: encoder queue = 1
- OPFS write backlog = 1
- AI tile concurrency = 1
- blur temporal samples أقل تحت extreme load
- checkpoints أكثر تكراراً
- cooperative yields دورية حتى تبقى الواجهة والـWebView responsive

هذا التصميم يفضّل إبطاء الرندر على إسقاط فريم أو نفاد الذاكرة.
