# BARSA SHOPI v5.2 — Smart Full Auto + POCO F6 Stability

## Implemented
- Full automatic AI model provisioning is enabled by default.
- Core sequence: Mobile SR x3 -> RIFE 4.9 -> YuNet Face Detector.
- Extended sequence: GFPGAN 1.4 is attempted automatically in the background when storage/network conditions are safe.
- Manual "Load all now" forces the extended model attempt.
- Every catalog model still requires size/hash verification and a real inference self-test before READY.
- Model downloads are sequential and large models stream into OPFS instead of keeping a second full copy in RAM.
- Automatic retries happen when network comes online, connection changes, or the app returns to foreground.
- Persistent browser storage is requested at startup when supported.
- POCO F6 profile was tuned toward Android WebView stability: previewScale 0.9, 3 workers, 256 tile, single AI tile concurrency.
