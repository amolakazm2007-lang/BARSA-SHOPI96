# BARSA SHOPI v5.3 — Pro Controls

## Focus
No new monitoring feature was added. This phase focuses on direct user control, stronger Blur Studio, clearer manual values, and export presets.

## Added
- Editable numeric value beside Quality Lab sliders.
- Editable numeric value beside Face Lab sliders.
- Editable numeric value beside DaVinci Mini color sliders.
- Blur Shutter Angle control (0–720 degrees), mapped to real blur amount (`angle / 360`, clamped by the engine).
- Blur presets: Low, Medium, Natural, Gameplay, Cinematic.
- Existing dedicated Blur-only MP4 renderer retained.
- Export presets: Social HQ, Master Quality, POCO F6 Fast, Custom 40 Mbps.
- Manual values remain editable after applying any preset.

## Blur source direction
The Blur Studio follows the main user-facing concepts documented by f0e/blur (blur amount, output FPS, weighting modes, interpolation, pre-interpolation, deduplicate and advanced Gaussian controls), while using BARSA SHOPI's own mobile temporal engine and RIFE/ONNX architecture.
