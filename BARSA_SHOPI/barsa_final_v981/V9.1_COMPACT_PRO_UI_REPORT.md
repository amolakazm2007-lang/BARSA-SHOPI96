# BARSA SHOPI v9.1 — COMPACT PRO UI

## الهدف
تقليل التعقيد البصري بدون حذف أي محرك. الواجهة تعرض سبع عائلات واضحة فقط، وكل عائلة تجمع المحركات المتشابهة اختصاصياً.

## الواجهة المبسطة
1. تنظيف الجودة: denoise / temporal denoise / deblock / deband / artifacts / chroma / mosquito / compression recovery.
2. استعادة التفاصيل: detail / fine detail / texture / micro texture / structure / fusion / edges.
3. الحدة والوضوح: clarity / local contrast / smart sharpen / dehalo / anti-ringing.
4. الوجوه والبورتريه: face detection + face model + face/eye/hair detail + cleanup + tone protect.
5. الحركة والنعومة: RIFE + temporal reconstruction + anti-flicker + scene protection.
6. تثبيت الفيديو: Stabilization فقط، غير مدموج مع RIFE.
7. الألوان: Color Engine controls الأساسية.

Blur يبقى تبويباً مستقلاً ورندر مستقل، والتصدير يبقى مستقلاً.
