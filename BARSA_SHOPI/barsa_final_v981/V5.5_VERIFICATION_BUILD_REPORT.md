# BARSA SHOPI v5.5 Verification Build

## Goal
Turn the existing device test into a user-visible Verification Center that runs real smoke tests on the actual Android/WebView device instead of relying only on source/unit checks.

## Added on-device checks
- H.264 encode smoke: 1080p60, 1080p120, 4K30, 4K60
- Quality aggregate pixel processing
- Quality control matrix (denoise, detail, sharpen, exposure, contrast, saturation, vibrance, temperature, dehaze, vignette, grain)
- Color engine
- .cube LUT parser/application
- CPU frame worker
- Streaming audio DSP + FFmpeg audio filter graph
- Temporal denoise / anti-flicker consistency path
- OPFS + IndexedDB write/finalize/delete session smoke
- Real media probe on bundled WebM through MediaInputEngine/Mediabunny
- Temporal Motion Blur frame emission
- FFmpeg WASM runtime load
- Mobile SR runtime self-test if installed
- Real-ESRGAN runtime self-test if installed/downloaded
- RIFE runtime self-test if installed/downloaded
- GFPGAN runtime self-test if installed/downloaded
- CodeFormer runtime self-test if installed/downloaded
- YuNet runtime self-test if installed/downloaded
- Safe AI tile probe
- Cancel / restart job self-test

## Auto model verification
The Verification Center has an enabled-by-default option to automatically install missing production models. A model is only reported PASS through each model engine's runtime self-test.

## Local regression in this environment
- 98/98 dependency-independent regression tests: PASS
- Source policy: PASS
- Final audit: PASS
- 44 source modules checked
- 14 critical runtime assets checked and hashed

## Environment limitation
The full Node test command also contains three tests that import `mediabunny` or `playwright`. The local dependency installation in this sandbox timed out, so those package-backed Node/browser tests cannot execute here. They are not counted as PASS. Their corresponding device paths are now covered by the on-device Verification Center (media probe/storage/runtime), while GitHub Actions can install the declared dependencies with `npm ci` and run the complete suite.
