# BARSA SHOPI v8.8 — RESILIENCE + FACE/PORTRAIT V3 + COMPRESSION RESCUE

## Implemented

### Render Resilience Engine
- New internal `RenderResilienceEngine`.
- Samples queue pressure and browser heap pressure when available.
- Under ELEVATED/HIGH/CRITICAL pressure it reduces encoder queue, OPFS write backlog and AI tile concurrency.
- Never requests frame dropping, FPS changes or resolution changes.
- Records backend fallbacks and recovery actions into render metadata.
- Works together with Frame Integrity Guard, back-pressure and long-render governor.

### POCO F6 sustained 4K policy
- RenderLoadGovernor now recognizes POCO F6 device profile.
- 4K/high-load POCO F6 render uses sustained policy: queue 1, write backlog 1, tile concurrency 1, frequent yields/checkpoints.
- Output resolution/FPS remain unchanged.

### Compression Rescue V3
- `mosquitoNoise` stage for codec edge residue.
- `compressionRecovery` stage for block-boundary/flat-area reconstruction.
- Both are real pixel effects in RealtimePreview/CPU worker fallback and are part of scene-aware smart planning.
- Both are exposed in Arabic Quality Lab and included in All Engine Boost.

### Face / Portrait V3
- Added real local face finishing controls:
  - Eye Detail V3
  - Hair Detail V3
- Both run only inside detected/restored face crops.
- Existing Face Detail, Skin Cleanup, Micro Contrast and Skin Tone Protect remain.
- All Engine Boost now includes the new V3 face controls without changing manual model selection.
